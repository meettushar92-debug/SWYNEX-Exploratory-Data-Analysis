# SWYNEX - Exploratory Data Analysis

## Project Overview

This project was completed as part of my Data Analyst Internship at SWYNEX Technologies.

For this task, I performed Exploratory Data Analysis (EDA) on the cleaned Online Retail dataset from Task 1 using Microsoft Excel and PivotTables.

## Analysis Performed

- Country-wise Revenue Analysis
- Daily Revenue Trend
- Top 10 Products by Revenue
- Total Quantity by Country
- Average Price by Country
- Negative Quantity Analysis
- Average Order Value (AOV)

## Key Insights

- Total Revenue: ₹192,734.82
- United Kingdom generated the highest revenue: ₹177,620.90
- 3-Dec recorded the highest daily revenue: ₹68,027.59
- Average Order Value: ₹420.82
- Total Negative Quantity: -240 units
- PAPER CHAIN KIT 50'S CHRISTMAS generated the highest revenue among the Top 10 products: ₹4,987.26

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts

## Key Learning

This task helped me understand how Exploratory Data Analysis can be used to identify trends, patterns, and useful business insights from a dataset.
